# UI Integration Tests

## Структура проекта
- `config/` — Конфигурация (settings.py, constants.py, sections.py — описания разделов)
- `pages/` — Page Objects (BasePage, LoginPage, SectionPage)
- `components/` — Компоненты таблицы (пагинатор, сортировка, фильтр)
- `helpers/` — Вспомогательные функции (разбор ячеек, мягкие проверки)
- `tests/` — UI-тесты (тонкий слой, параметризованы по разделам)
- `unit_tests/` — Офлайн-тесты фреймворка (запускаются в CI)
- `utils/` — Утилиты (логгер с маскированием)

## Как добавить раздел
Добавить `Section(...)` в `config/sections.py`: таблицу, колонки с типами и нужные
сортировки/фильтры. Тесты структуры, пагинации, сортировки и фильтров подхватят его автоматически,
а `unit_tests` проверят, что описание согласовано (колонки существуют, типы дат верные).
