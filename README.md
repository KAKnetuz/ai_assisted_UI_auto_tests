Набор интеграционных UI-тестов, демонстрирующих автоматизацию веб-приложений с помощью **Playwright** и **Python**. Проект построен на архитектуре **Page Object Model (POM)**, использует переиспользуемые хелперы и мягкие ассерции для повышения надежности.

---

## 📖 О проекте

Этот репозиторий создан в учебно-демонстрационных целях для портфолио. В нем реализованы базовые и продвинутые сценарии тестирования UI: от проверки отображения элементов до сложной фильтрации и сортировки данных в таблицах.

> 🔒 **Примечание для портфолио:** код представляет собой демонстрационную версию. Реальные адреса стендов, учётные данные, названия внутренних UI-компонентов, маршруты и бизнес-данные заменены на обобщённые плейсхолдеры для соблюдения NDA корпоративного клиента.

---

## ✨ Особенности

*   **Полный цикл UI-тестирования:** Проверка видимости вкладок, иконок, кнопок и структуры таблиц.
*   **Динамическая пагинация:** Тестирование смены лимита отображения строк (10, 20, 50, 100) и навигации по страницам (вперед/назад, первая/последняя страница).
*   **Сортировка данных:** Проверка корректной сортировки столбцов (числовые значения, текст, даты) с поддержкой полного цикла (ASC → DESC → RESET).
*   **Фильтрация контента:** Тестирование работы поиска по тексту, множественного выбора чекбоксов и фильтрации по диапазонам дат.
*   **Продвинутый стек:** Переиспользуемые хелперы (`FilterHelper`, `SortingHelper`, `PaginationHelper`) и мягкие ассерции (`SoftAssert`) для накопления ошибок без остановки выполнения теста.

---

## 🚀 Технологии

*   **Язык:** Python 3.13+
*   **Фреймворк тестирования:** Pytest 8.4+
*   **Браузерная автоматизация:** Playwright (Chromium)
*   **Параллельный запуск:** pytest-xdist
*   **Управление конфигурацией:** python-dotenv
